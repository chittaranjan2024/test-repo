# 🧑‍💼 Spring Boot + MySQL Employee CRUD Application

This is a simple **CRUD** application built using **Spring Boot** and **MySQL** that lets you manage employee records via RESTful APIs.

It’s perfect for learning how to build REST APIs with Spring Boot, integrate MySQL as a database, and run everything locally using Eclipse.

---

## 🚀 Features

- ✅ Create, Read, Update, Delete Employee Records
- ✅ RESTful API using Spring Boot
- ✅ MySQL Database Integration
- ✅ Uses Spring Data JPA for simplified database access
- ✅ Project setup in Eclipse IDE

---

## 🛠 Tech Stack

- Java 17+
- Spring Boot 3.x
- Spring Data JPA
- MySQL
- Maven
- Eclipse IDE
- Lombok

---

## 🧰 Prerequisites

Make sure you have the following installed:

- [Java JDK 17+](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
- [MySQL](https://dev.mysql.com/downloads/)
- [Eclipse IDE for Java Developers](https://www.eclipse.org/downloads/)
- [Lombok Plugin for Eclipse](https://projectlombok.org/setup/eclipse)
- Maven (bundled with Eclipse or install separately)
